# Screenshots

--debug`), with the sample designs and pane layouts saved in the documents'
`views` section; downscaled to 1600 px. Appearance in the file name.

|---|---|

| `ghosts-stray-dark.png` | ghost path ranking, ghost irradiance map, stray-light maps per class |
| `optimize-running-dark.png` | Optimize while running: iteration, merit, log merit history, Stop and Cancel |
| `optimize-result-light.png` | the result as a before/after comparison, applied as one undoable step |
| `tolerance-dark.png` | ranked sensitivities and Monte-Carlo statistics with histogram |
| `solves-light.png` | Apply Solves: the dry-run report before the commit |
